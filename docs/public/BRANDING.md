# PropertyHub branding assets

The supplied archive contains one connected-buildings design: three buildings around
a shared teal space. Its old README listed three concepts; only this one design is
included here. Files named `(1)` in the archive were byte-identical PNG duplicates
and are not distributed.

`public/branding/` contains the horizontal light/dark SVG wordmarks, light/dark SVG
icons, a theme-aware SVG favicon, two 32px PNG favicon fallbacks and a 180px Apple
touch icon. Other export sizes, monochrome previews and the original archive are
not shipped. The wordmark uses paths, not text or runtime fonts. No SVG scripts,
external resources, embedded images or font files are included. The favicon's only
style is a local color-scheme rule; the application also selects its theme variant.

Colors: navy `#1B2A4A`, teal `#14A39A`; dark-theme artwork uses `#F7F8FA` and
`#2EC4B6`. The provided description identifies the outlined wordmark as Manrope,
by Mikhail Sharanda. No font software is bundled; the upstream project is licensed
under [SIL OFL 1.1](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt).

These are user-supplied design assets. No trademark search, clearance or exclusivity
is claimed. The site's copyright footer does not change third-party licenses or
claim ownership of user data. No project-wide license is introduced by this package.
