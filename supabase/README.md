# Supabase

DEV-01 не създава проект или SQL схема. `migrations/` е мястото за бъдещите реални timestamp миграции.
Следващият пакет започва с минимално ядро за достъп и управленски обхват. Всяка изложена таблица получава grants/RLS още при създаването и allow/deny проверки с две синтетични организации.
Service-role ключове, DB пароли и access tokens не принадлежат във frontend, VITE_* или Git.
